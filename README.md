# Weather App

A simple web application that fetches and displays weather information for a given location.

## Features

- Search for any location to get accurate weather data.
- Hourly forecast: View summary of weather conditions for each hour of the day.
- 15-day forecast: Get an extended outlook with weather summaries for the next 15 days.
- Temperature toggle: Switch between Celsius and Fahrenheit.
- Dynamic weather icons: See different icons representing current weather conditions (sunny, cloudy, rainy, etc.).

## Tech Stack

- HTML
- CSS
- JavaScript
